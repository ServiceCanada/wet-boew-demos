Canada Strong theme

Styles for the Canada Strong campaign pages. Refer to the working examples for a visual of the code below.

Working examples

  • Landing page layout
  • Support page layout

CSS classes

canada-strong
Wrapper for the campaign content. The classes below are scoped to it.
hero
The fade over the image is part of the image, so the hero only sets the image position. Use it with bg-cover and data-bgimg-srcset, with the no-image value at 1199w to remove the decorative image on screens narrower than 1200 pixels.
title-bar
Maroon title bar with white text, applied directly on the heading.
card-audience
Maroon card with white text and links, and a short red underline below the heading. Use it with p-3 mb-3 for the spacing, and with hght-inhrt inside a wb-eqht-grd row for cards of equal height.
card-support
Bordered card with a round icon. Use it with panel panel-default, and with hght-inhrt inside a wb-eqht-grd row for cards of equal height. Add position-relative to the card and stretched-link to the heading link to make the whole card clickable.
end-page-promo
Navy promotion with a round white icon, and white text and links. Place it after the page content, in a full-width section using bg-light py-3 for the grey band.
support-banner
Maroon banner with a white h1 and an image, used on sub pages. Put the heading before the image in the source order. This class is used with panel.

Theme elements

Add the canada-strong class to the element wrapping the page content. Layout and spacing use the WET and GCWeb utility classes. In the working examples, the hero and the banner use a h2 so the documentation page keeps a single h1, and the hero container is a container-fluid since the examples already sit inside a container. On a real page, use <h1 property="name" id="wb-cont"> and a container.

Hero

The fade over the image is part of the image, so the hero only sets the image position. Use it with bg-cover and data-bgimg-srcset, with the no-image value at 1199w to remove the decorative image on screens narrower than 1200 pixels.

Support cards

Bordered card with a round icon. Use it with panel panel-default, and with hght-inhrt inside a wb-eqht-grd row for cards of equal height. Add position-relative to the card and stretched-link to the heading link to make the whole card clickable.

Working example

New support measures

This program will provide flexible and easy-to-access support for businesses facing economic challenges.

Regional tariff response initiative

This will help small and medium-sized enterprises respond to tariff pressures.

BDC's Pivot to Grow program

Working capital for businesses facing cash-flow shortfalls as a result of U.S. tariffs.

Canada Strong Diversification Fund

Support for tariff-impacted companies with shovel-ready projects.
