Managed Web Services Components Canada.ca MWS Components

Search

<gcds-ext-mws-search> provides a standalone Canada.ca search form with accessible query suggestions fetched as a person types. It is based on GCDS's search component. This version adds the following properties:

  • suggestions-access-token
  • suggestions-organization-id
  • suggestions-max-items
  • suggestions-min-characters
  • suggestions-pipeline
  • suggestions-search-hub
  • suggestions-endpoint

All of those properties are used to configure the search suggestions.

Configure suggestions (default)

An access token is the only mandatory property to display suggestions.

<gcds-ext-mws-search
  action="https://www.canada.ca/en/sr.html"
  suggestions-access-token="xx27395007-5c98-43c0-bef0-553131a34e90"
></gcds-ext-mws-search>

Configure suggestions (custom)

You can adjust the number of suggestions displayed and the minimum number of characters required to trigger suggestions. The rest of the properties should remain unchanged for most use cases.

<gcds-ext-mws-search
  action="https://www.canada.ca/en/sr.html"
  suggestions-access-token="xx27395007-5c98-43c0-bef0-553131a34e90"
  suggestions-max-items="10"
  suggestions-min-characters="5"
></gcds-ext-mws-search>

Properties

Attribute Description Type Default
action Sets the action for the search form. Default will be canada.ca global search string '/sr/srb.html'
method Set the form method of the search form "get" | "post" 'get'
name Set the name of the search input string 'q'
placeholder Set the placeholder and label for the search input. Becomes "Search [placeholder]" string 'Canada.ca'
search-id Set the id of the search input string 'search'
suggestions-access-token Bearer token used to access the suggestions API. Suggestions are disabled when omitted. string ''
suggestions-endpoint Base URL for the Canada.ca query suggestions API, without the /querySuggest path. string 'https://apps.canada.ca/search'
suggestions-max-items Maximum number of suggestions requested from the API. number 5
suggestions-min-characters Minimum number of input characters before suggestions are requested. number 3
suggestions-organization-id Organization ID used to access the suggestions API. string ''
suggestions-pipeline Pipeline sent with each suggestions request. string ''
suggestions-search-hub Search hub sent with each suggestions request. string ''
value Set the value of the search input string

Events

Event Description Type
gcdsBlur Emitted when the search input has lost focus. void
gcdsChange Emitted when the search input value has changed. string
gcdsFocus Emitted when the search input has gained focus. void
gcdsInput Emitted when the search element has received input. string
gcdsSubmit Emitted when the search form has submitted. string
