Combobox

The <gcds-ext-mws-combobox> is a custom element that provides a dropdown list of options for the user to select from.

Default

<gcds-ext-mws-combobox
    label="Vegetable(s)"
    name="vegetables-combobox"
    input-id="vegetables-combobox"
    options='[{"cucumber": "Cucumber"},{"carrot": "Carrot"},{"broccoli": "Broccoli"},{"spinach": "Baby Spinach"}]'
>
</gcds-ext-mws-combobox>

Using Slots

<gcds-ext-mws-combobox
    label="Fruit(s)"
    name="fruits-combobox"
    input-id="fruits-combobox"
>
    <select slot="options">
        <option value="apple">Apple</option>
        <option value="banana">Banana</option>
        <option value="orange">Orange</option>
        <option value="grape">Grape</option>
    </select>
</gcds-ext-mws-combobox>

With hint and select all

<gcds-ext-mws-combobox
    label="Animal(s)"
    name="animals-combobox"
    input-id="animals-combobox"
    options='[{"lion": "Lion"},{"elephant": "Elephant"},{"giraffe": "Giraffe"},{"zebra": "Zebra"}]'
    enable-select-all
    hint="Select at least one animal."
    required
>
</gcds-ext-mws-combobox>

Inside a form, required

Submit 
<form novalidate action="#">
    <gcds-error-summary listen></gcds-error-summary>
    <gcds-ext-mws-combobox
        label="Animal(s)"
        name="animals-combobox"
        input-id="animals-combobox"
        options='[{"lion": "Lion"},{"elephant": "Elephant"},{"giraffe": "Giraffe"},{"zebra": "Zebra"}]'
        hint="Select at least one animal."
        required
    ></gcds-ext-mws-combobox>
    <gcds-button type="submit"> Submit </gcds-button>
</form>

Properties

Attribute Description Type Default
autofocus Specifies if an input element should be focused on component render. boolean false
disabled Specifies if an input element is disabled or not. boolean false
enable-select-all If true, a "Select All" option will be displayed at the top of the list of options. boolean false
error-message Error message for an invalid input element. string
form The ID of the form that the input field belongs to. string
hide-label If true, the label will be visually hidden but still accessible to screen readers. boolean false
hint Hint displayed below the label and above the input field. string
input-id (required) Id attribute for the combobox input element. string
label (required) Form field label string
name (required) Name attribute for the combobox input element. string
options JSON option array, or URL returning objects with `name` and `tag` fields. SuggestionOption[] | string
required Specifies if a form field is required or not. boolean false
validate-on Set event to call validator "blur" | "other" | "submit" 'blur'
value Initial selected values. string | string[]

Events

Event Description Type
gcdsBlur Emitted when the input loses focus. void
gcdsChange Emitted when the input has changed. SuggestionOption[]
gcdsError Emitted when the element is invalid. object
gcdsFocus Emitted when the input has focus. void
gcdsInput Emitted when the element has received input. string
gcdsValid Emitted when the input has a validation error. object

Slots

Slot Description
options The options slot is for providing the list of available options.
