CSV to Tables Prototype

  • Documentation
  • Questions or comments?

Example

Loads data directly from a CSV file and populates a table using the DataTables plugin into WET providing searching, sorting, filtering, pagination and other advanced features for tables.

Example 1

<table class="wb-tables table" data-wb-csv="ajax/team-ontario-games-en.csv">

This example uses data from Open Data, showing the participation of Team Ontario in the Canada Games.

Example 2

<table class="wb-tables table table-striped table-hover" data-wb-csv="ajax/eqarchive-en.csv">

This example uses data from Open Data, showing earthquake data from 2019.
