Nettoyage d'IPI

La composante Nettoyage d'IPI détecte les informations personnelles identifiables (IPI) dans les champs de formulaire que vous marquez, présente à l'utilisateur une fenêtre de confirmation affichant les valeurs caviardées, puis remplace ces valeurs avant la soumission du formulaire.

À propos des motifs de détection de cette page

Cette page charge une version mise à jour de l'assistant de base wb.findPotentialPII(), reprenant les motifs proposés dans la demande de tirage nº 10117 de wet-boew. En plus des motifs déjà offerts dans la BOEW, elle détecte :

  • les adresses courriel masquées, y compris les domaines espacés et les adresses sans domaine de premier niveau
  • les adresses municipales en français et en anglais, avec ou sans direction ni article
  • les cases postales (case postale, casier postal, PO Box et leurs abréviations)

Cette substitution est temporaire et se trouve dans components/pii-scrub/pii-scrub.js. Elle devra être retirée une fois la demande de tirage fusionnée en amont et la dépendance wet-boew mise à jour.

Nouveaux motifs détectés

Utilisez ce formulaire pour mettre à l'essai les motifs ajoutés par la demande de tirage nº 10117. Aucune de ces valeurs n'est détectée par la version de l'assistant actuellement offerte dans la BOEW.

Instructions

Remplissez le champ Détails avec l'une des valeurs suivantes, puis soumettez :

  • Adresse municipale (français) : J'habite au 1250, rue Sainte-Catherine Ouest
  • Adresse municipale (anglais) : I live at 123 Main St West, Ottawa
  • Case postale : Case postale 789, succursale B
  • Case postale (anglais) : Send it to PO Box 1234
  • Courriel masqué : Écrivez-moi à jean . tremblay + impot @ exemple . com
  • Courriel sans domaine de premier niveau : equipe_soutien@mon-domaine
Afficher le code 
<form action="pii-scrub-fr.html" class="wb-pii-scrub">
	<div class="form-content">
		<div class="form-group">
			<label for="details"><span class="field-name">Détails</span></label>
			<textarea class="form-control" id="details" name="details" data-scrub-field rows="4" cols="50"></textarea>
		</div>
		<button type="submit" class="btn btn-primary">Soumettre</button>
	</div>
</form>

Vous trouverez ci-dessous un exemple démontrant l'implémentation de la composante Nettoyage d'IPI avec un formulaire soumis avec l'envoi via Ajax. Cet exemple démontre également l'utilisation des options scrubChar et modalTemplate.

Instructions

Seul le champ Commentaires possède un attribut data-scrub-field.

Remplissez le champ Commentaires avec les informations suivantes :
Visa : 4916 0739.3667-6891, Master : 5428735149026050, NAS : 123 123-123, Code postal : K2C 3N2, 1250, rue Sainte-Catherine Ouest

Merci !

Une erreur s'est produite. Veuillez soumettre vos informations par un autre moyen.

Exemple avec validation de formulaire

Vous trouverez ci-dessous un exemple démontrant l'implémentation de la composante Nettoyage d'IPI avec la validation de formulaire. La fenêtre de confirmation n'est affichée qu'une fois le formulaire validé.

Instructions

Seul le champ Commentaires possède un attribut data-scrub-field.

Remplissez le champ Commentaires avec les informations suivantes :
Visa : 4916 0739.3667-6891, NAS : 123 123-123, Code postal : K2C 3N2, Case postale 789

Afficher le code 
<div class="wb-frmvld mrgn-bttm-md">
	<form action="pii-scrub-fr.html" class="wb-pii-scrub">
		<div class="form-content">
			<div class="form-group">
				<label for="fname1" class="required"><span class="field-name">Prénom</span> <strong class="required">(obligatoire)</strong></label>
				<input class="form-control" id="fname1" name="fname1" type="text" autocomplete="given-name" required="required" data-rule-minlength="2">
			</div>
			<div class="form-group">
				<label for="lname1" class="required"><span class="field-name">Nom de famille</span> <strong class="required">(obligatoire)</strong></label>
				<input class="form-control" id="lname1" name="lname1" type="text" autocomplete="family-name" required="required" data-rule-minlength="2">
			</div>
			<div class="form-group">
				<label for="comments2">Commentaires</label>
				<textarea class="form-control" id="comments2" name="comments2" data-scrub-field rows="4" cols="50"></textarea>
			</div>
			<button class="btn btn-primary">Soumettre</button>
		</div>
	</form>
</div>

Vous trouverez ci-dessous un exemple démontrant l'implémentation de la composante Nettoyage d'IPI avec la validation de formulaire et l'envoi via Ajax.

Instructions

Seul le champ Problème possède un attribut data-scrub-field.

Remplissez le champ Problème avec les informations suivantes :
Visa : 4916 0739.3667-6891, NAS : 123 123-123, 123 Main St West

Merci !

Afficher le code 
<div class="wb-frmvld mrgn-bttm-md">
	<form action="pii-scrub-fr.html" class="wb-pii-scrub wb-postback" data-wb-postback='{"success":".success-message-2","failure":".failure-message-2"}'>
		<div class="form-content">
			<div class="form-group">
				<label for="nomComplet" class="required"><span class="field-name">Nom complet</span> <strong class="required">(obligatoire)</strong></label>
				<input class="form-control" id="nomComplet" name="nomComplet" type="text" required="required" data-rule-minlength="2">

			<div class="form-group">
				<label for="probleme">Problème</label>
				<textarea class="form-control" id="probleme" name="probleme" data-scrub-field rows="4" cols="50"></textarea>

</div>

Fonctionnement

  • Ajoutez la classe wb-pii-scrub à l'élément form.
  • Ajoutez l'attribut data-scrub-field à chaque champ dont la valeur doit être vérifiée.
  • Donnez une étiquette à chaque champ marqué. Encadrez le texte de l'étiquette dans <span class="field-name"> lorsque celle-ci contient du texte supplémentaire à ne pas répéter dans la fenêtre de confirmation.
  • Configurez au besoin la composante avec l'attribut data-wb-pii-scrub :
    • scrubChar : la chaîne servant à remplacer les IPI détectées. Valeur par défaut : ********.
    • moreInfo : le code HTML affiché dans la section en savoir plus de la fenêtre par défaut.
    • modalTemplate : un sélecteur ciblant un élément <template> à l'intérieur du formulaire, utilisé à la place de la fenêtre par défaut. Placez un élément data-scrub-modal-fields à l'endroit où les valeurs caviardées doivent être listées, et l'attribut data-scrub-submit sur le bouton de confirmation.

Les détails complets des options se trouvent dans la documentation du nettoyage d'IPI.
