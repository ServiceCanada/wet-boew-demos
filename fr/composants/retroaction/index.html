Rétroaction

Le composant <gcds-ext-mws-feedback> recueille la rétroaction de l'expérience sur une page. Lorsqu'il est utilisé, il apparaît en bas de la page, juste avant la date de modification.

Par défaut

<gcds-ext-mws-feedback></gcds-ext-mws-feedback>

Propriétés

Attributs Description Type Valeur par défaut
action Defines the URL where the feedback should be submitted string 'https://feedback-retroaction.canada.ca/api/QueueProblemForm'
section Defines the section where your page resides (sent as data via the form submission) string ''
theme Defines the theme of your page (sent as data via the form submission) string ''

Événements

Événement Description Type
feedbackNo Triggered when the user select "No" void
feedbackSubmit Triggered when the user select "Yes" or submits a comment void

Emplacements

Emplacement Description
(default) The main content of the container.
