Lien en vedette

Le composant <gcds-ext-mws-featured-link> est un hyperlien court et descriptif que votre institution doit mettre en évidence sur une page d’accueil.

Par défaut

 
<gcds-ext-mws-featured-link link-text="[Titre de la promotion]" href="https://google.ca"></gcds-ext-mws-featured-link>

En utilisant les emplacements

 [Titre de la promotion2]

Ma description avec un texte long.

 
<gcds-ext-mws-featured-link bg-color="#cccccc">
    <a href="google.com" slot="link">[Titre de la promotion<sup>2</sup>]</a>
    <p slot="description">Ma description avec un <strong>texte</strong> long.</p>
</gcds-ext-mws-featured-link>

Propriétés

Attributs Description Type Valeur par défaut
bg-color Background color for the featured link section, as a hex value (e.g. "#FF0000"). string
description Description shown under the link. Optional, and takes priority over the `description` slot if both are provided. string
href URL for the featured link. Mandatory if the `link` slot is not used. string
link-text Text for the featured link. Mandatory if the `link` slot is not used. string

Événements

Aucun événement disponible pour ce composant.

Emplacements

Emplacement Description
description Optional. A `<p slot="description">text</p>` used to build the gcds-text shown under the link. Accepts HTML content. Ignored if the `description` prop is set.
link An `<a href="url" slot="link">text</a>` used to build the featured gcds-link. Accepts HTML content. Required if the `href` and `link-text` props are not set.
